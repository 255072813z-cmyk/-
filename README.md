# 拜毯（Ҷойнамоз / Джойнамоз）

> 原名"网上清真寺"。ҷойнамоз 是塔吉克语"礼拜毯"，家家都有，名字本身就是"在家礼拜"的意思；不叫"清真寺"，也避免被误解为另立清真寺。

给塔吉克斯坦和在俄罗斯的塔吉克穆斯林（哈乃斐学派）的在家礼拜助手。冬天大雪、严寒出不了门时，在家也能按时、规范地礼拜，像在清真寺里和大家站在一起。

- 不用注册、不用登录，不收集任何个人信息；设置和记录只存在用户自己的手机上
- 没有功德积分、没有排名、没有付费
- 网站 + 安卓/苹果应用；核心功能完全离线。后台（可选）只做在线人数、签名的远程配置和匿名总数统计
- 界面：塔吉克语、俄语、乌兹别克语（拉丁字母）、吉尔吉斯语（初稿，待审定）、中文（开发用）

## 第一阶段：今天的礼拜 + 在家礼拜（已完成）

| 跟着做 | 每番拜按逊奈 / 主命 / 威特尔分开，一步一步：姿势 + 阿拉伯文 + 译音 + 中文 + 出处；画面里一排人和你做同一个动作 |

## 第二阶段：斋月（已完成）

| 页面 | 内容 |
|---|---|
| 斋月 | 斋月前显示"还有几天"；斋月中显示今天的停止吃喝 / 开斋时间和倒计时，开斋时念词，整月时间表 |
| 封斋记录 | "今天封了斋，记一下"；30 天格子可改成"封了 / 没封（要补）"；只存本机，不计分不排名 |

| 间歇拜 | 哈乃斐 20 拜、每 2 拜一组：跟着做、记组数，礼完接威特尔 |
| 古兰经 30 天读完 | 每天 1 卷（卷起止章节与页码，麦地那标准本 604 页），读完打勾 |
| 首页 | 斋月期间，最上面显示封斋/开斋倒计时 |

**封斋与开斋时间**

- 停止吃喝 = 天文黎明（18°）前 10 分钟，宁早勿晚。对照第三方转载的 2027 年塔吉克乌莱玛委员会斋月表（它的封斋时间比 18° 黎明早 6～7 分钟），本站每天都不晚于它（见 `tests/ramadan.test.mjs`）
- 开斋 = 日落；当地清真寺习惯再等几分钟宣礼，页面写明以当地宣礼为准
- 用户按清真寺微调时，封斋只会更早、开斋只会更晚
- 斋月日期、节日按乌姆古拉历法推算（1448 年斋月：2027-02-08 起，开斋节 03-09，古尔邦节 05-16），页面写明"以当地清真寺公布为准"

## 第三阶段：三个空间（已完成）

| 空间 | 内容 |
|---|---|
| 清真寺（入口） | 三道门；门上显示真实在线人数（只读查询，看人数不算人头） |
| 礼拜大殿 | 可左右走动的全景：米哈拉布、敏拜尔、吊灯、4 排 40 张垫子。点空垫子坐下，安静待一会儿；坐满了排队，有人起身时空垫子自动给排在最前面的人 |
| 庭院 | 葡萄架、塔普昌、苏扎尼、茶和馕、小水池；倒茶、掰馕、听流水声（默认静音）；显示下一番拜，宣礼前 10 分钟请你进大殿 |
| 诗歌夜 | 宵礼后到晨礼前开放；鲁达基、鲁米、哈菲兹、萨迪的诗句轮换（波斯文原文 + 塔吉克文 + 中文意译）；合成配乐默认静音 |

- 画里的人是插画（剪影、背影，不画五官）；**在线人数只显示真实统计，没有连接计数服务时不显示任何人数**
- 底部导航：今天 · 在家礼拜 · 清真寺 · 斋月 · 赞念（朝向在"在家礼拜"里）
- 诗句原文出自 Ganjoor 古典诗歌库；塔吉克文为本站转写，中文为本站意译
- 配乐、流水声都是在手机上实时合成的，不是录音

**在线人数服务（`server/`）**

- 只在内存里数连接：每个连接一个服务端随机编号，不收集、不保存任何个人信息，不写数据库
- `room.js` 规则（垫子、排队）；`worker.js` 线上版（Cloudflare Workers + Durable Objects，免费套餐可用）；`dev-server.mjs` 本地版
- 本地运行：`npm run presence`，网页地址后加 `?presence=ws://127.0.0.1:8787`
- 线上版已在 Cloudflare 官方运行时（Miniflare/workerd）测试：`npm i --no-save miniflare@3.20250718.3 && node server/test-worker.mjs`

## 上线（全部做完后一起上线）

## 宗教内容的依据

**礼拜时间**（在手机上离线计算，计算库 adhan-js）

- 晨礼、宵礼：太阳在地平线下 18°（卡拉奇伊斯兰科学大学法，哈乃斐地区常用）
- 晡礼：哈乃斐学派（影长为物高 2 倍）
- 谨慎取整：开始时间宁晚勿早（晡礼 +45 秒、其余 +5 秒后向后取整），日出向前取整。
  经 `check:astro` 全年 4392 个时间点核对，没有一个开始时间早于真实时刻，最多晚 2.1 分钟
- 塔吉克斯坦全年 UTC+5，按固定偏移计算，与手机时区设置无关
- **待确认**：塔吉克斯坦乌莱玛委员会（shuroiulamo.tj）有官方日历，第三方网站转载的数字与天文计算有差异（例如晌礼）。
  开发时官方网站无法访问，未能核实。页面上已写明"以当地清真寺公布为准"，并提供按清真寺微调

**念词**：古兰经用 Tanzil 标准文本，中文用马坚译本（`npm run quran` 生成，未手改）；圣训念词逐字核对原文，出处写在每条念词下面（见 `src/content/recitations.js` 顶部说明）。

**伊斯兰历**：乌姆古拉历法推算，页面写明"以当地宗教机构宣布为准"，可手动 ±2 天。

**朝向**：天房坐标 21.4225241°N, 39.8261818°E；磁偏角取 WMM-2025 模型（杜尚别 +4.7°，胡占德 +5.3°）。

## 隐私

对外请求只有这些：

- 天气：只带**城市**坐标去 Open-Meteo（"我的位置"也只发最近城市的坐标），不带 Cookie、不带来源网址，本机缓存 1 小时
- 后台（部署后）：在线人数（只收发人数和垫子状态）、取远程配置、匿名统计（每个使用日一条，没网时先存在手机里、有网时补传；没有编号和位置，设置里可关；内容见 `docs/后台与安全.md`）

不设 Cookie、不接第三方统计或广告。位置只在用户点"用我的位置"时读一次粗略位置，只在手机上用；第一次打开按手机**时区**猜城市，不读位置。
