# 网上清真寺

给塔吉克斯坦穆斯林（哈乃斐学派）的在家礼拜助手。冬天大雪、严寒出不了门时，在家也能按时、规范地礼拜，像在清真寺里和大家站在一起。

- 不用注册、不用登录，不收集任何个人信息；设置和记录只存在用户自己的手机上
- 没有功德积分、没有排名、没有付费
- 纯静态网站，没有后端、没有数据库；手机、平板、电脑都能打开

## 第一阶段（已完成）

| 页面 | 内容 |
|---|---|
| 今天（首页） | 五番拜时间（杜尚别 / 胡占德）、下一番倒计时、到点轻声提醒（默认静音）、公历 + 伊斯兰历、日出日落、下雪 / 严寒时的"在家礼拜"提示 |
| 在家礼拜 | 入口：小净 → 朝向 → 跟着做 → 礼拜后赞念 |
| 小净 | 11 步图文（剪影插图高亮要洗的部位），标明主命 / 圣行，冬天抹皮袜、坏小净的事 |
| 跟着做 | 每番拜按逊奈 / 主命 / 威特尔分开，一步一步：姿势 + 阿拉伯文 + 译音 + 中文 + 出处；画面里一排人和你做同一个动作 |
| 朝向 | 手机罗盘（已按磁偏角修正为真北）、角度、到麦加的大圆航线地图 |
| 赞念 | 33 遍一组的计数器，最后一句凑满 100；只存在本机 |
| 设置 | 字号（标准 / 大 / 特大）、提醒、按自己清真寺的时间微调、伊斯兰历 ±2 天调整 |

## 运行

```bash
npm install
npm run dev        # 本地开发
npm run build      # 生成 dist/，整个目录放到任意静态网站空间即可
```

演示参数（加在地址后面）：

- `?weather=heavy`（大雪）/ `snow` / `cold` / `clear`：模拟天气，看冬季模式
- `?now=2026-12-18T15:20`：把时钟拨到杜尚别当地这个时刻

## 检查

```bash
npm test             # 单元测试：时区无关、拜数、步骤、念词完整、红线
npm run check:astro  # 全年逐日与高精度天文库比对礼拜时间（离线）
npm run check:times  # 与 aladhan.com 比对（需联网）
npm run build && npm run shots    # 手机/平板/电脑三种尺寸截图 + 横向溢出 + 报错检查
npm run build && npm run verify   # 首屏速度、到点提醒、罗盘、本地记录、第三方请求、夜间模式
```

## 宗教内容的依据

**礼拜时间**（在手机上离线计算，计算库 adhan-js）

- 晨礼、宵礼：太阳在地平线下 18°（卡拉奇伊斯兰科学大学法，哈乃斐地区常用）
- 晡礼：哈乃斐学派（影长为物高 2 倍）
- 谨慎取整：开始时间宁晚勿早（晡礼 +45 秒、其余 +5 秒后向后取整），日出向前取整。
  经 `check:astro` 全年 4392 个时间点核对，没有一个开始时间早于真实时刻，最多晚 2.1 分钟
- 塔吉克斯坦全年 UTC+5，按固定偏移计算，与手机时区设置无关
- **待确认**：塔吉克斯坦乌莱玛委员会（shuroiulamo.tj）有官方日历，第三方网站转载的数字与天文计算有差异（例如晌礼）。
  开发时官方网站无法访问，未能核实。页面上已写明"以当地清真寺公布为准"，并提供按清真寺微调

**念词**：古兰经用 Tanzil 标准文本，中文用马坚译本（`npm run quran` 生成，未手改）；圣训念词逐字核对原文，出处写在每条念词下面（见 `src/content/recitations.js` 顶部说明）。

**伊斯兰历**：乌姆古拉历法推算，页面写明"以当地宗教机构宣布为准"，可手动 ±2 天。

**朝向**：天房坐标 21.4225241°N, 39.8261818°E；磁偏角取 WMM-2025 模型（杜尚别 +4.7°，胡占德 +5.3°）。

## 代码结构

```
src/
  main.js            入口：路由、导航、走时、提醒
  router.js          路由（以后加 斋月 ramadan、三个空间 spaces）
  core/              计算：礼拜时间、伊斯兰历、朝向、天气、存储、设置、提醒
  content/           宗教内容：念词、拜数与步骤、小净、古兰经（生成）、地图（生成）
  pages/home.js      首页
  pages/pray/        在家礼拜：入口、小净、跟做、朝向、赞念
  pages/settings.js  设置
  ui/                插图（全部 SVG 剪影，无五官）、念词卡片
  i18n/              界面文字（现有中文；预留塔吉克语 tg、俄语 ru）
  styles/            样式（绿 + 金 + 米白；夜间自动深色）
scripts/             生成数据、核对时间、截图与验收
tests/               单元测试
```

## 隐私

唯一的对外请求是天气：只带城市坐标去 Open-Meteo（免费、无需密钥），结果在本机缓存 1 小时。不用定位、不设 Cookie、不接任何统计或广告。
