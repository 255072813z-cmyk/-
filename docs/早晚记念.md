## 核对方法

- 阿拉伯文：从 fawazahmed0/hadith-api 的圣训阿拉伯原文**用程序截取**（按字母定位起止、连同符号原样截出），不手打；并和第二个出处交叉核对字母是否一致。
- 穆斯林圣训集的编号：数据源自带的是顺序编号，和通行的阿卜杜·巴基编号不同。这里按原文查找，用数据里附带的通行编号核对（2691、2692、2709）。
  同时复核了礼拜念词里已经引用的穆斯林编号 772、591、595、597、234，都对得上。
- 第 112–114 章：原文和意思直接用古兰经页的数据（Tanzil 原文 + 各语言的出版译本），不另写。
- 意思、贵处：本站意译（中文、塔吉克语、俄语、乌兹别克语、吉尔吉斯语），**初稿，请伊玛目审定**。
- 译音（拉丁、塔吉克西里尔、俄语西里尔、乌兹别克拉丁）只是跟读的辅助，以阿拉伯文为准。
