## 乌兹别克语、吉尔吉斯语译本的选择（上线前请当地宗教局确认）

- **乌兹别克语 Muhammad Sodiq Muhammad Yusuf**：乌兹别克斯坦最通行的译本，作者是前穆夫提，哈乃斐学派。QuranEnc 上另外两个乌兹别克语译本（Rowwad 中心、Alauddin Mansur）由沙特机构审校，没有用。
  乌兹别克斯坦现在通用拉丁字母，所以转成拉丁字母；如果需要西里尔字母版，原始数据就是西里尔字母，加一个选项即可。
- **吉尔吉斯语 Шамсуддин Хакимов**：能拿到完整电子文本的只有这一个（原为沙特法赫德国王古兰经印刷厂版，QuranEnc 审校）。
  个别经文（如 48:10"Аллахтын Колу"）按字面直译，和俄语 Кулиев 的处理一样；吉尔吉斯斯坦穆斯林宗教局如果有推荐译本（例如 Чубак ажы Жалилов 的译本）并能授权，换成它更好——只需改生成脚本再运行一次。

## 需要你决定的：塔吉克语用哪个译本

可选的有三个（都在 quran.com / Tanzil 上）：

1. **Оятӣ（现用）**：纯译文，简洁中立。缺点：译者是伊朗学者，用"Худо"而不是"Аллоҳ"。
2. **Хоҷа Миров（Khawaja Mirof）**：塔吉克本地学者，但正文里夹了大段注释（"简明经注"风格），而且把认主独一分成"养育、受拜、名称属性"三类——这是萨拉菲派的讲法，萨拉菲派 2014 年起在塔吉克斯坦被禁，**不建议用**。
3. **Pioneers of Translation Center（沙特"先驱翻译中心"）**：现代塔吉克语，方括号补充说明。信条上同样偏沙特，**不建议用**。

如果当地宗教委员会有认可的塔吉克语译本、并且能拿到电子文本和授权，换成它最好（只需改生成脚本，再运行一次）。

## 修正记录（数据源的扫描错误，只改错字、多余符号，不改词句意思）

塔吉克语（对照 Оятӣ 波斯文原译）：

- 7:37 «0н → «Он；"мекардед. акиуи куҷоянд?." → "мекардед, акнун куҷоянд?»"；"Гӯянд;" → "Гӯянд:"
- 7:49 "инхо6 хамом … шумо7 … хурда … ра^мати … бих, ишт шавед8 … гамгин" → "инҳо ҳамон … шумо … хӯрда … раҳмати … биҳишт шавед … ғамгин"
- 7:60 «Ту] ро → «Туро；8:67 насазад* → насазад,；10:40 IIарвардигори → Парвардигори
- 27:56 去掉混进正文的"(Пораи 20)"；71:23 "накунед:," → "накунед:"，"Насрро*" → "Насрро"

乌兹别克语（Tanzil uz.sodik）：

- 混进西里尔字母词里的拉丁字母（X、K、C、c、x）换回西里尔字母（转写时自动处理）；2:151 末尾多余的 '、79:22 多余的 ¬ 去掉

吉尔吉斯语（QuranEnc kyrgyz_hakimov）：

- 混进的拉丁字母 c/C 换回西里尔字母；软连字符去掉
- 15:32 «0о → «Оо（字母 О 错成数字 0）；16:61 多余的 *；27:11 多余的阿拉伯字母 ظ；27:12 多余的阿拉伯字母 آ

中文（马坚）：

- 扫描时把"一"认成了"－"（如"－切"→"一切"）、半角标点、叩头处的"※"：统一排版清理
- 44:43、56:52 "（木+苦）"造字占位 → "攒楛木"
- **4:12 两个数据源都在半句处断掉**，不凭记忆补经文，页面上如实注明"数据源此节不完整，请以马坚译本原书为准"
