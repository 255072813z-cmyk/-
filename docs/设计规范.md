# 设计规范

目标：每一页看起来都是同一个应用——井井有条、一眼找到要点的东西、老人也看得清。
变量都在 `src/styles/tokens.css`，动效在 `src/styles/motion.css`。新加页面、改样式时只用下面这几档，不要另起数值。

## 一、颜色（绿 + 金 + 米白，夜间自动切换）

| 用途 | 变量 |
|---|---|
| 页面底色 / 次一级底色 | `--bg` / `--bg-2` |
| 卡片 | `--card` |
| 正文 / 次要文字 / 说明文字 | `--ink` / `--ink-2` / `--muted` |
| 主色（按钮、选中、完成） | `--green`（深一点的按钮底边 `--primary-deep`） |
| 点缀（星、称号、书签、进度） | `--gold`，浅底 `--gold-soft`，金色文字 `--gold-ink` |
| 细线 | `--line`，统一用 `--hairline`（1 像素实线） |

不用大红大紫；红色 `--danger` 只用于真正的警告。

## 二、字号（7 档）

| 变量 | 大小 | 用在 |
|---|---|---|
| `--fs-xs` | 0.78rem | 角标、章节号、出处 |
| `--fs-sm` | 0.875rem | 注释、次要信息、分组小标题 |
| `--fs-md` | 1rem | 正文 |
| `--fs-lg` | 1.125rem | 卡片标题、列表主文字 |
| `--fs-xl` | 1.375rem | 子页面标题 |
| `--fs-2xl` | 1.75rem | 标签页大标题 |
| `--fs-3xl` | 2.25rem | 大数字（今天读了几节等） |

标题用衬线体（`--font-zh-serif`），正文用无衬线体；阿拉伯文一律用 `--font-ar`（Amiri）、从右往左。数字（时间、计数）用等宽数字 `font-variant-numeric: tabular-nums`。

## 三、间距、圆角、阴影

- 间距只用 4 / 8 / 12 / 16 / 20 / 24 / 32（`--sp-1`…`--sp-8`）。页面左右留 16，卡片之间 12，卡片内边距 16。
- 圆角：小块 10（`--r-sm`）、按钮和小卡片 14（`--r-md`）、卡片 18（`--r-lg`）、标签和胶囊按钮全圆（`--r-pill`）。
- 阴影三级：贴着的 `--shadow-1`、卡片 `--shadow-2`、弹出层 `--shadow-3`。

## 四、页面结构（每页都一样）

1. **标签页首页**（今天以外的四个标签）：`<header class="ph">` 左对齐大标题 + 下面一行说明（`.ph-sub`）。有插图的页面，插图在标题上面。
2. **子页面**：`.page-head`——左上角返回按钮 + 标题。返回到所属的标签页（我的 → 坚持、亲友圈、时间表、设置）。
3. **分组**：一页里内容多时，用 `<h2 class="sec">` 小标题分成几块（例如"工具""了解更多""我的记录""时间和设置"）。
4. **卡片**：一张卡片只讲一件事；卡片标题前面是八角星（`star8(18)`）。
5. **列表行**：最小高度 56–64，行与行之间细实线；左边可以有 38×38 的图标块（`.li-ico`），右边是 `›`。虚线只用来表示状态（"没封""漏了"）。
6. **按钮**：主按钮（绿色，有厚度，按下会陷下去）每屏最多一个；其他用浅色按钮。高度 52 / 44 / 34 三档。

## 五、动效

- 只动位置和透明度，时长 0.2–0.5 秒，弹性曲线 `--ease-spring`、缓出曲线 `--ease-out`。
- 换页内容依次浮现；按钮按下会陷；完成、解锁时才放大动画（彩屑、徽章）。
- 循环动画（呼吸的光圈、灯火、轻轻招呼）只改颜色、阴影、透明度，不挪位置。
- 系统开了"减少动态效果"时全部关闭。

## 六、文字

- 所有界面文字放在 `src/i18n/`（中文开发版、塔吉克语、俄语），代码里不写死文字（`npm test` 会检查）。
- 宗教内容写明出处，拿不准的写"以当地清真寺公布为准"。
- 个人记录的地方都写一句"只存在这台手机上，不计分、不排名"。
