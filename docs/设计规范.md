# 设计规范

目标：每一页看起来都是同一个应用——井井有条、一眼找到要点的东西、老人也看得清。
变量都在 `src/styles/tokens.css`，动效在 `src/styles/motion.css`。新加页面、改样式时只用下面这几档，不要另起数值。

## 一、颜色（绿 + 金 + 米白，夜间自动切换）

| 用途 | 变量 |
|---|---|
| 页面底色 / 次一级底色 | `--bg` / `--bg-2` |
| 卡片 | `--card` |
| 正文 / 次要文字 / 说明文字 | `--ink` / `--ink-2` / `--muted` |
| 主色（按钮、选中、完成） | `--green`（深一点的按钮底边 `--primary-deep`） |
| 点缀（星、称号、书签、进度） | `--gold`，浅底 `--gold-soft`，金色文字 `--gold-ink` |
| 细线 | `--line`，统一用 `--hairline`（1 像素实线） |

不用大红大紫；红色 `--danger` 只用于真正的警告。

## 二、字号（7 档）

正文基准：标准 17 像素（`html` 106.25%），"大" 19、"特大" 21。显示方式选"年纪大的人"时整体再大一档：20 / 22 / 24。

| 变量 | 大小 | 用在 |
|---|---|---|
| `--fs-xs` | 0.78rem | 角标、章节号、出处 |
| `--fs-sm` | 0.875rem | 注释、次要信息、分组小标题 |
| `--fs-md` | 1rem | 正文 |
| `--fs-lg` | 1.125rem | 卡片标题、列表主文字 |
| `--fs-xl` | 1.375rem | 子页面标题 |
| `--fs-2xl` | 1.75rem | 标签页大标题 |
| `--fs-3xl` | 2.25rem | 大数字（今天读了几节等） |

标题用衬线体（`--font-zh-serif`），正文用无衬线体；阿拉伯文一律用 `--font-ar`（Amiri）、从右往左。数字（时间、计数）用等宽数字 `font-variant-numeric: tabular-nums`。

## 三、间距、圆角、阴影

- 间距只用 4 / 8 / 12 / 16 / 20 / 24 / 32（`--sp-1`…`--sp-8`）。页面左右留 16，卡片之间 16，卡片内边距上下 20、左右 16。行距 1.75。
- 圆角：小块 10（`--r-sm`）、按钮和小卡片 14（`--r-md`）、卡片 18（`--r-lg`）、标签和胶囊按钮全圆（`--r-pill`）。
- 阴影三级：贴着的 `--shadow-1`、卡片 `--shadow-2`、弹出层 `--shadow-3`。

## 四、页面结构（每页都一样）

1. **标签页首页**（今天以外的四个标签）：`<header class="ph">` 左对齐大标题 + 下面一行说明（`.ph-sub`）。有插图的页面，插图在标题上面。
2. **子页面**：`.page-head`——左上角返回按钮 + 标题。返回到所属的标签页（我的 → 坚持、亲友圈、时间表、设置）。
3. **分组**：一页里内容多时，用 `<h2 class="sec">` 小标题分成几块（例如"礼拜前后""了解更多""我的记录""时间和设置"）。用穆斯林一看就懂的词，不用产品化的说法（"工具""计划""模块"之类）。
4. **卡片**：一张卡片只讲一件事；卡片标题前面是八角星（`star8(18)`）。
5. **列表行**：最小高度 56–64，行与行之间细实线；左边可以有 38×38 的图标块（`.li-ico`），右边是 `›`。虚线只用来表示状态（"没封""漏了"）。
6. **按钮**：主按钮（绿色，有厚度，按下会陷下去）每屏最多一个；其他用浅色按钮。高度 52 / 44 / 34 三档。

## 五、动效

- 只用 `transform` 和 `opacity`（不引起重排，低端手机也流畅）；`npm run verify` 会检查所有关键帧里没有 left/top/width/height/margin 之类。时长 0.2–0.5 秒，弹性曲线 `--ease-spring`、缓出曲线 `--ease-out`。
- 换页约 200 毫秒：卡片从上到下依次淡入、轻轻上浮（最多错开 6 个，每个 30 毫秒）；往里走从右边滑入、返回从左边。
- 倒计时数字一位一位放，变了的那一位平滑滚过去（`setCount`，见 `src/ui/motion.js`）。
- 按钮按下会陷；完成、解锁时才放大动画（彩屑、徽章）。
- 循环动画（呼吸的光圈、灯火、轻轻招呼）用单独一层，只变透明度和大小，不挪位置。
- 系统开了"减少动态效果"时全部关闭。
- 顶栏是不透明的实色，不用半透明、毛玻璃。

## 首页（"今天"）

一个穆斯林打开首页，3 秒内要知道今天该做什么、下一番拜几点。所以只放三层：

1. **顶部**：左边日期（公历 + 伊斯兰历），右边城市。城市和手机不在一个时区时，城市下面加一行"当地时间"。
2. **中间**："下一番拜"大卡片：上面一条小插图（天色、雪景），下面拜名、时间（最大的字）、倒计时、"跟着做"按钮。到点前 10 分钟加一句温和的话（"晌礼还有 10 分钟，先把手头的事收个尾，去做个小净吧"）。
3. **下面**："今天要做的事"——礼拜时间表（可以打勾）、封斋状态（斋月倒计时 / 明天是不是圣行斋日）、早晚记念（该念的时候才出现）、今日圣训。天气不好时，主卡片下面多一张"在家礼拜"卡片。

其他入口都在底部导航里；"坚持"在"我的"里。

**两种显示方式**（第一次打开时在首页问一句"你是年轻人，还是年纪大的人？"——页面里的卡片，不弹窗；设置里随时改）：

- 年轻人：上面这样，精致简洁。
- 年纪大的人：大字极简，首页只有日期城市、下一番大卡片和时间表（不打勾）；天气不好只在主卡片里说一句；斋月里加上封斋卡片。

**节日**（`src/core/festival.js`）：斋月、斋月最后十天、开斋节（1–3 日）、都尔黑哲月头十天、阿拉法日、古尔邦节（4 天）、伊斯兰历新年、阿舒拉日——主卡片上换一句问候语和一个小图标，颜色微调（斋月夜蓝、节日金色、朝觐月绿色），版面不变。

## 六、文字

- 所有界面文字放在 `src/i18n/`（中文开发版、塔吉克语、俄语、乌兹别克语、吉尔吉斯语），代码里不写死文字（`npm test` 会检查）。乌兹别克语较长，按钮、标签要留出换行的余地。
- 宗教内容写明出处，拿不准的写"以当地清真寺公布为准"。
- 个人记录的地方都写一句"只存在这台手机上，不计分、不排名"。
