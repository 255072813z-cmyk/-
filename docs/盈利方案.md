# 盈利方案（建议，供决定）

前提（不能碰的红线）：不卖功德、不收供养、应用里不接支付；不注册、不收集个人信息；不打扰礼拜。
所以思路是：**用户永远免费、简单；钱从机构和合作方那里来，不从信徒的信仰里来。**

## 推荐路线

| 阶段 | 做什么 | 收入来源 | 对用户的影响 |
|---|---|---|---|
| 上线后 0–6 个月 | 完全免费、无广告，先把口碑和用户量做起来 | 无（可申请基金会、社会组织的数字项目资助） | 无 |
| 6–12 个月 | **机构版**：清真寺、宗教管理部门付年费，在应用里发布本寺/本地的官方时间表、公告（后台已经做好：签名配置 + 来源标注） | 机构年费，线下签约、开发票 | 用户看到更准的本地时间，**是加分** |
| 12 个月起 | **侨民服务目录**：给在俄罗斯的塔吉克务工者列出经过核实的合作方（清真餐馆、法律咨询、劳动许可/证件办理、汇款、语言课） | 合作方按年付"上架费"（不按点击，不追踪用户） | 单独一页，不出现在礼拜页面；可在设置里关掉 |
| 长期 | **公益赞助**：某个功能（例如斋月时间表）注明"由××支持"，一行字，不跳转、不弹窗 | 赞助方 | 几乎无感 |

## 为什么这样选

- **机构版最稳**：清真寺和宗教管理部门本来就要把时间表、公告发给信众，现在多靠纸张和群聊。我们给的是"一处发布、所有人手机上准时看到"，而且有签名防篡改。收费对象是机构，信众一分钱不花。
- **侨民服务是真需求**：在俄罗斯的塔吉克务工者，最头疼的是证件、法律、汇款、找清真饭馆。核实过的名单本身就有价值，合作方愿意为"被信任的渠道"付费。
- **不做的事**：
  - 应用内购买、会员、"高级版"——违反"不接支付"，也会让老人困惑。
  - 个性化广告、广告联盟（谷歌/Yandex 广告）——会收集数据，会在礼拜时弹出，伤害信任。
  - "捐款换回赐""点灯""代念"——红线。
  - 卖数据——绝不。统计本来就只有匿名总数。

## 不影响"简单便捷"的规则（写进合同）

1. 礼拜时间、跟做礼拜、小净、朝向、赞念、斋月这些页面里**永远没有任何商业内容**。
2. 不弹窗、不插屏、不推送商业通知；提醒只用于礼拜和斋月。
3. 合作方信息只出现在单独的"服务"页，明确标"合作方"，用户可以在设置里隐藏。
4. 不追踪用户点了什么；合作方拿不到任何用户数据。
5. 宗教内容不受赞助方影响；官方时间只接受清真寺、宗教管理部门，并写明来源。

## 需要你决定的事

1. 是否走"机构版"路线？若是，先找 1–2 家杜尚别或莫斯科的清真寺试点（免费试用 3 个月）。
2. 侨民服务目录要不要做？做的话需要有人负责核实合作方（这是信任的根本）。
3. 收入用什么主体收（公司 / 社会组织）——影响开发票和合同。

技术上，机构版用现有后台就能做：给机构开一个只能改"本寺公告和时间校正"的发布权限（下一步可做：多把签名钥匙，每家机构一把，只能改自己城市）。
