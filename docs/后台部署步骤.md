# 后台部署步骤（手机上也能做）

后台负责：大殿在线人数和垫子、亲友圈、远程公告和时间校正、匿名统计。
不部署后台时应用照样能用，只是这些联网功能不显示。

整个过程不需要电脑：在 Cloudflare 和 GitHub 网页上点几下，部署由 GitHub 自动完成。
仓库是公开的，所以**所有口令和密钥都只放在 GitHub 的 Secrets 里**，部署时不会打印到日志里。

## 一、Cloudflare（免费套餐够用）

1. 打开 dash.cloudflare.com 注册账号（邮箱即可），选免费套餐。
2. 左边菜单点 **Workers & Pages**。第一次进来会让你选一个 workers.dev 子域名（例如 `joynamoz`），选好记下来。
3. 记下 **Account ID**：Workers & Pages 页面右侧就有（一串 32 位的字母数字）。
4. 建一个 API 令牌：右上角头像 → **My Profile** → **API Tokens** → **Create Token** →
   模板选 **Edit Cloudflare Workers** → Account Resources 选你的账号 → **Continue to summary** → **Create Token**。
   令牌只显示这一次，马上复制。

## 二、GitHub 里存机密

**更安全的做法**（推荐）：仓库 → **Settings** → **Environments** → **New environment**，名字填 `api`，勾 **Required reviewers** 填你自己，
再在这个环境的 **Environment secrets** 里加下面几项。这样以后每次部署后台都要你在 GitHub 上点"批准"。

也可以放在仓库级：仓库 → **Settings** → **Secrets and variables** → **Actions** → **Secrets** 标签 → **New repository secret**，依次加：

| 名字 | 填什么 |
|---|---|
| `CLOUDFLARE_API_TOKEN` | 上面复制的令牌 |
| `CLOUDFLARE_ACCOUNT_ID` | 上面记下的 Account ID |
| `ADMIN_TOKEN` | 管理口令，**至少 24 位**的随机字符。iPhone 上可以让"密码"应用生成两个强密码连在一起 |

## 三、第一次部署

1. 仓库 → **Actions** → 左边 **部署后台** → **Run workflow**。
2. 如果设了 `api` 环境的批准：页面上会出现 **Review deployments**，点进去批准。
3. 等它变成绿色的对勾（约 2 分钟）。点进去看"部署"那一步，最后有后台地址，形如
   `https://masjid-api.<你的子域名>.workers.dev`。

管理后台以后怎么用、钥匙怎么保管、出事怎么办，见 [后台管理方案.md](后台管理方案.md)。

## 四、两步验证和配置签名密钥

1. 用手机浏览器打开 `后台地址/admin/`，点登录框下面的 **第一次部署：生成密钥**。
2. **两步验证**：点"生成两步验证密钥"。在手机上的 Google Authenticator（或 Microsoft Authenticator）里选"输入设置密钥"，
   账户名填"清真寺后台"，密钥填那串字母。再把同一串字母（去掉空格）存到 GitHub Secrets，名字 `ADMIN_TOTP`。
3. **配置签名密钥**：点"生成新密钥"，下载的私钥文件**保存好、不要发给任何人**（以后发布公告要用它签名）。
   显示出来的公钥要填两个地方：
   - GitHub **Secrets** 里加 `CONFIG_PUBLIC_KEY`（服务器检查用）
   - GitHub **Variables** 标签里加 `VITE_CONFIG_PUBKEY`（打包网站和应用用）
4. GitHub **Variables** 标签里再加 `VITE_API_URL` = 后台地址（`https://` 开头，末尾不要斜杠）。

## 五、再部署一次，让网站连上后台

1. **Actions → 部署后台 → Run workflow**（这次会把 `ADMIN_TOTP`、`CONFIG_PUBLIC_KEY` 存到服务器）。
2. **Actions → 发布网站 → Run workflow**（网站带上后台地址重新打包）。
3. 打开网站的"清真寺"页，门上显示"此刻 N 人"就说明连上了。
4. 用 `后台地址/admin/` 登录：口令 + 手机验证器上的 6 位数字。

## 安全上已经做好的（不用你操心）

- 只接受本网站和手机应用发来的请求；没填网站地址时一律拒绝网页来的请求。
- 每个 IP 每分钟最多 300 次请求，管理后台 30 次；房间里每个连接 10 秒最多 20 条消息。
- 管理后台：口令 + 两步验证；同一个 6 位数字只能用一次；连续输错 5 次锁 1 小时，全站 1 小时输错 30 次全部锁住。
- 公告和时间校正必须用你手里的私钥签名，服务器和手机各验一次；旧配置不能覆盖新配置。
- 不收集个人信息：统计只有每天的总数，亲友圈只有昵称和打卡日期。

## 建议再做（可选）

Cloudflare 后台 → 你的域名或 Workers → Security：打开 **Bot Fight Mode**；给 `/admin/*` 加一条 WAF 规则，只允许你所在的国家访问。
