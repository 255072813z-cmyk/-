# 翻译说明（塔吉克语 tg、俄语 ru）

开发阶段用中文。正式上线前，整个应用要换成塔吉克语和俄语。代码已经准备好：**翻译只需要改语言文件，不用改代码**。

## 要翻译的东西

| 位置 | 内容 | 怎么做 |
|---|---|---|
| `src/i18n/zh.js` | 全部界面文字（约 480 条） | 复制为 `tg.js`、`ru.js`，逐条翻译右边的文字 |
| `src/content/recitations.js` | 每条念词的意思（`zh` 字段）、出处（`src.zh`） | 在同一条里加 `tg: '…'`、`ru: '…'` |
| `src/content/recitations.js` | 章名（`SURAH_NAME`） | 同上 |
| `src/content/quran.js` | 古兰经各节的中文译文 | 见下面"古兰经译文" |
| `src/content/poems.js` | 诗人名、说明、出处、中文意译 | 加 `ru` 字段；塔吉克语界面直接显示 `cyr`（西里尔字母原诗），不需要译文 |

翻译完成后，在 `src/i18n/index.js` 里把对应语言的 `ready` 改成 `true`，设置页的语言按钮就能点了。

## 规则

1. **保留 `{名字}` 占位符**，例如 `'{city}到麦加约 {km} 公里'`：`{city}`、`{km}` 原样保留，位置可以按语法调整。
2. **俄语的单复数**：需要变化的词条写成对象，例如
   `'fast.daysLeft': { one: 'До Рамадана {n} день', few: '… {n} дня', many: '… {n} дней', other: '… {n} дня' }`。
   程序会按数字自动选。
3. **阿拉伯文原文不动**（念词、古兰经、月名、拜名的阿拉伯文）。
4. **宗教内容必须由母语者和当地伊玛目审定**后才能上线。拿不准的写"以当地清真寺/伊玛目为准"，不要编。
5. 测试会检查：代码里不许写死文字；每个用到的词条都存在；占位符成对。改完运行 `npm test`。

## 古兰经译文（注意版权）

- 中文现用马坚译本。
- 俄语、塔吉克语需要选**有授权或已进入公有领域**的译本，并在页面上注明译者和来源。上线前确认授权，不能随便抓取网上的译文。
- 念词（赞主词、作证词等）的意思是本站自己的意译，可以直接翻译。

## 译音

念词现在的译音用拉丁字母。塔吉克、俄罗斯用户习惯西里尔字母，计划为每条念词加 `trCyrl` 字段（西里尔字母译音），界面按语言选择显示哪一种。
