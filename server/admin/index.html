    签名密钥
    
      
    远程配置必须用私钥签名，手机才会接受。这样即使服务器或管理口令被人拿到，也改不了手机上显示的内容。
    
      
      
        
    1. 点下面的按钮生成一对密钥。私钥文件会下载到你的电脑上——请备份到安全的地方（例如加密 U 盘），不要发给任何人，不要放进代码仓库。
      2. 
        
    2. 把显示出来的公钥，填到两个地方：GitHub 仓库的变量 VITE_CONFIG_PUBKEY（打包应用用），Cloudflare 的机密 CONFIG_PUBLIC_KEY（服务端检查用）。
      3. 
        
    3. 重新打包应用。之后每次发布配置都用这个私钥文件签名。
      4. 
      
    
      
    换密钥需要发布新版应用（旧应用只认旧公钥），所以平时不要换。私钥丢了的话，旧应用就收不到新配置了。
    
      
      
    
    
    
    
    
      
    两步验证（登录后台用）
    
      
    第一次部署时做一次：点下面的按钮生成一个两步验证密钥。
    
      
      
        
    1. 在手机上打开 Google Authenticator（或 Microsoft Authenticator），选"输入设置密钥"，账户名填"清真寺后台"，密钥填显示出来的那串字母。
      2. 
        
    2. 在电脑上运行 npx wrangler secret put ADMIN_TOTP，粘贴同一串字母。
      3. 
        
    3. 以后登录后台，除了口令，还要输入手机上显示的 6 位数字。
      4. 
      
    
      
    换手机前先把验证器迁移到新手机；丢了的话重新生成一个、重新设置 ADMIN_TOTP 即可（旧的立即失效）。
